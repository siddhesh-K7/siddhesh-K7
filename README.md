## ⚡ A Quick Python Challenge

**One change. Two lists. What gets printed?**

```python
original = [[1, 2], [3, 4]]
copied = original.copy()

copied[0].append(99)

print(original)
```

<details>
<summary><b>👀 Reveal the output and explanation</b></summary>

<br>

```python
[[1, 2, 99], [3, 4]]
```

`original.copy()` creates a **shallow copy**.

The outer list is new, but the nested lists are still shared.
Changing `copied[0]` therefore changes the same inner list
referenced by `original[0]`.

For independent nested lists in this example:

```python
from copy import deepcopy

copied = deepcopy(original)
```

**Takeaway:** Knowing what your variables reference matters.

</details>
