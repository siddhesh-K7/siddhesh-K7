## 🎮 Bonus Level: Can You Predict It?

```python
items = [1, 2, 3]
alias = items
alias += [4]

print(items)
```

<details>
<summary><b>🕹️ Reveal the answer</b></summary>

```text
[1, 2, 3, 4]
```

Both names refer to the same list. For lists, `+=` extends the
existing list in place, so the change is visible through `items`.

**Bonus question:** What if the line were `alias = alias + [4]`?

<details>
<summary><b>🏆 Reveal the bonus answer</b></summary>

`items` would remain `[1, 2, 3]`.

Here, `+` creates a new list and assignment makes `alias` refer to it.
The original list is unchanged.

</details>
